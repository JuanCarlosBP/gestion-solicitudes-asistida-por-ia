¿Vienes a probar el proyecto?

El formulario de esta página muestra cómo se inicia sesión en una instalación de la aplicación con cuentas propias: cada persona usa su correo y su contraseña.

En esta demostración no tienes una cuenta personal ni necesitas crear una. Para probarla, no uses el formulario de acceso: sigue estos pasos.

  1. Abre Demo y pulsa Reservar mi espacio.
  2. Elige Entrar como solicitante para crear un borrador, añadir conceptos y presentar una solicitud.
  3. Vuelve a Demo, sin liberar el espacio, y elige Entrar como supervisor para aprobar o rechazar la solicitud.
  4. Vuelve a Demo y entra como auditor para consultar el historial. Al terminar, pulsa Liberar mi espacio.

Los tres roles utilizan los datos ficticios de tu reserva, separados de los de otros visitantes. No introduzcas contraseñas de IONOS, GitHub ni de tu ordenador.
