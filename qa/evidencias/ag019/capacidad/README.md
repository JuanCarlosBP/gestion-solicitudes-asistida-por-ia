# Revisión de capacidad conservada

Estos ficheros proceden de la revisión de las cuatro pasadas locales A1/A2/B1/B2.
No son nuevas ejecuciones en GitHub ni mediciones del hardware de IONOS.
Se preservan sus bytes y la interpretación de CPU; los datos brutos de las pasadas
se conservan en AG-016. El menor perfil candidato pasa dos veces; la selección de
4 GB para publicar ofrece margen y no se atribuye al laboratorio equivalencia con
el proveedor. El JSON de revisión contiene sus límites y condiciones originales.

La corrección del evaluador no modifica las muestras; las evaluaciones fallidas
anteriores permanecen en la historia y no se convierten retrospectivamente en PASS.
